# A field map of neo AI safety and security labs

An interactive map of new AI safety and security labs, grouped into territories by research agenda. Click any logo for a short profile of the lab, its agenda and its public work.

Built from the "List of AI Safety labs" sheet (Labs tab, 24 Nov 2026). Logos are each lab's own site icon; labs without one show initials.

Open `index.html` in a browser, or view it on GitHub Pages.
